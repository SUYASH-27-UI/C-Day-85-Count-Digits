# C Day 85 - Count Digits in a Number

## Description
This C program counts the total number of digits in an integer using a while loop.

## Example
**Input:**
`4567`

**Output:**
`Total digits: 4`

## Concepts Used
- While Loop
- If-Else Statement
- Integer Division
- Counter Variable

## How to Run
1. Save the code as `count_digits.c`.
2. Compile the program using a C compiler.
3. Run the program and enter a number.
